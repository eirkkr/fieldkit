# Style

- Use hyphens (`-`), not em dashes, in all project files.
- Markdown: wrap prose and code at the repo's configured line length (table rows
  exempt). The exact limit and any linter enforcement are per-repo.
- Write all prose in Australian English (`-ise`/`-isation`, `behaviour`,
  `colour`, etc.) - comments, docstrings, docs, commit/PR/issue text, branch
  names. Exception: match the existing spelling of an identifier or name defined
  elsewhere (function, config key, dependency, API field), even in prose.
